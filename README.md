# FileFlow 智慧檔案整理助手（純前端網頁版）

一個無需安裝後端、直接在瀏覽器本機運行的檔案整理儀表板，使用瀏覽器 **File System Access API** 授權存取本機資料夾。

## 功能特色

- **純本機運作、零上傳**：檔案掃描與移動完全在您的電腦中進行。
- **現代化儀表板**：提供掃描統計 KPI、SVG 檔案類型分佈圓環圖與容量佔比長條圖。
- **彈性分類規則**：內建圖片、文件、試算表與簡報、影片、音訊、程式碼、壓縮檔、安裝檔、設計與字型等分類，並可自訂資料夾名稱與副檔名。
- **執行前預覽（Dry-run）**：清楚列出每個檔案移動前後路徑，支援搜尋、篩選與單筆勾選排除。
- **安全防護與復原**：同名檔案預設自動編號（如 `photo (1).jpg`）避免覆蓋，並支援當次工作階段一鍵復原與匯出 JSON 整理記錄。
- **模擬體驗模式**：未授權真實資料夾前，也可一鍵載入範例檔案體驗完整流程。

## 啟動方式

> 瀏覽器的 File System Access API 需要透過 `http://localhost` 或 `https://` 開啟（直接雙擊 HTML 的 `file://` 模式會被瀏覽器基於安全考量限制存取本機資料夾）。

1. 雙擊資料夾內的 `start.bat`（會自動使用 Python 啟動本機靜態伺服器並開啟瀏覽器）。
2. 或在終端機執行：
   ```powershell
   python -m http.server 8765
   ```
   接著使用最新版 **Chrome** 或 **Edge** 開啟 `http://localhost:8765`。
